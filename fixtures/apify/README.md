# Фикстуры Apify

Сюда кладутся настоящие выгрузки датасета `apify/instagram-scraper`.

## Зачем

1. **Разработка без расхода кредитов.** При `APIFY_MOCK=1` код берёт данные отсюда,
   а не из платного API. Free tier — около 1850 результатов в месяц, тратить их
   на отладку нельзя (см. `PLAN.md` §1).
2. **Проверка схемы.** Тест `src/lib/instagram/fixtures.test.ts` прогоняет
   нормализацию на этих файлах и ловит расхождение ожидаемых полей с фактическими.
   Схема у акторов со временем меняется — юнит-тесты на выдуманном объекте
   такое не поймают.

## Как наполнить

1. Открыть `apify/instagram-scraper` в консоли Apify.
2. Скормить 3–5 реальных ссылок на рилсы (разных авторов, желательно один
   с закрытыми лайками — чтобы попал случай `likesCount: -1`).
3. Скачать результат в JSON.
4. Положить файлы сюда: `fixtures/apify/*.json`.

Пока папка пуста, тест на реальных данных помечается как пропущенный —
это видно в выводе `npm test`.
